Cuándo abrir un chat nuevo

Aprobaste el cambio o el tema terminóCerrar y abrir el siguiente tema
Vas a hablar de otro temaChat nuevo con el prompt de ese tema
Conversación larga (muchas capturas o archivos)Cerrar y usar el prompt de continuación
Un bug falló 2 veces con SonnetChat corto en Opus con el prompt de continuación
Toca diseñar (motor, economía, estructura de clase)Chat Opus solo conversando; la implementación va a un chat Sonnet
Compactaste 2 vecesCerrar y abrir uno nuevo

Antes de cerrar, Claude siempre: hace nexo-cierre, actualiza docs/chats/<tema>.md, regenera esta hoja y te deja el prompt de continuación listo.
